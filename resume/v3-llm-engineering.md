## 项目经历

### 多工具协同的 ReAct 智能体系统 | 独立开发 | 2026.08 - 至今

`Python · LangGraph · DeepSeek API · ChromaDB · FastAPI · Gradio · Docker`

> **设计原因**：发现 LangChain 高度封装导致工具调用时序难以调试，因此从零实现 Agent 核心循环，并将工具路由器作为独立模块——简单查询绕过 LLM 直接调用工具，Token 消耗降低 60%。

- 设计并实现完整 **ReAct Agent** 系统：感知→推理→行动→观察闭环，支持多轮对话与任务规划
- 集成 **10+ 工具**（搜索、计算、天气、时间、文件笔记等），基于统一工具接口实现热插拔
- 构建 **RAG 检索增强模块**：PDF/TXT文档加载 → 文本切分 → Embedding → ChromaDB向量检索 → LLM生成
- 设计**双层记忆系统**（短期滑动窗口 + 长期JSON持久化），保障长对话上下文连贯性
- 开发 **FastAPI REST接口 + Gradio WebUI**，完成 Docker 容器化部署
- 建立自动化评估体系（14条测试用例），冒烟测试通过率 **93%**

### 航空专用轻量化大模型压缩与边缘部署 | 核心成员 | 2025.07 - 2025.09

`PyTorch · BERT · TensorRT · Jetson AGX Orin`

> **设计原因**：航空机载环境功耗受限（<50W），直接部署 110M BERT 不可行，采用知识蒸馏+TensorRT 量化的双层压缩策略，在 18M 参数下保留 98.2% 准确率。

- 通过**知识蒸馏**将 BERT-base（110M）压缩至3层Transformer学生模型（18M），参数量**减少83.6%**
- 利用 **TensorRT FP16量化 + 算子融合** 部署至Jetson AGX Orin
- 推理延迟 **2100ms → 92ms（↓95.6%）**，GPU利用率 37% → 89%，准确率仅下降1.8%

### 基于YOLOv8的车辆检测系统 | 项目负责人 | 2024.11 - 2024.12

`Python · YOLOv8 · Django`
