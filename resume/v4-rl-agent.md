## 核心项目

### 基于深度强化学习的无人机避障算法研究 | 第一作者 | 2025.09 - 2026.04

`Python · PyTorch · SAC · PPO · Gym-PyBullet-Drones`

> **设计原因**：PPO 是 On-Policy 算法样本效率低但稳定，SAC 是 Off-Policy 最大熵算法探索能力强但易震荡——系统对比两者的设计选择是为了回答"动态障碍场景下哪种算法更优"这一开放问题。

- 独立实现 **PPO 与 SAC** 强化学习核心算法，在三维连续状态/动作空间下完成训练与对比实验
- 针对 SAC 在稀疏奖励环境中探索不足的问题，设计**动态熵温度自适应调节机制**，根据策略熵值动态调整探索强度
- 设计**规则化安全投影层**：通过数学约束限制动作空间，训练初期碰撞率**降低 80%**
- 开展4组对照实验（12次独立训练），从**成功率、碰撞率、收敛速度**三维度评估
- SAC在密集动态障碍下成功率比PPO高 **8%**，PPO收敛更平稳

### 多工具协同的 ReAct 智能体系统 | 独立开发 | 2026.08 - 至今

`Python · LangGraph · DeepSeek API · ChromaDB`

> **设计原因**：Agent 任务规划本质是序贯决策问题，与 RL 的 MDP 框架天然对应——搭建此系统是为后续将 RL（如 GRPO）应用于 Agent 工具调用策略优化做工程准备。

- 构建 ReAct Agent 系统，实现多轮推理与工具调用的完整闭环
- 设计**双层记忆系统**（短期+长期），保障多轮对话连续性
- 该工作为后续 **Agentic RL**（将强化学习应用于Agent任务规划与工具调用）奠定工程基础

### 光伏功率预测与空间降尺度研究 | 第二作者（EI会议） | 2024.12 - 2025.09

- 提出 KNN空间降尺度 + 随机森林回归 预测框架，RMSE**降低18.7%**，R²达0.92
- 论文发表于 **IEEE CISAT 2025（EI检索）**

### 脉冲星计时噪声与大气延迟建模 | 负责人 | 2024.08 - 2024.10

> **设计原因**：单一模型无法同时捕捉计时噪声的周期分量（傅里叶优势）和随机漂移（随机森林优势），故采用多模型融合策略。

- 利用**傅里叶回归**拟合计时噪声（拟合度 >97%），双指数平滑与随机森林预测趋势
- 基于Saastamoinen与Herring模型建立高频折射延迟模型（天顶延迟 ≤7.69ns）
- 获第十届"数维杯"国际数学建模竞赛 **国际二等奖**
