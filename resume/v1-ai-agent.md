## 核心项目

### 多工具协同的 ReAct 智能体系统 | 独立开发 | 2026.08 - 至今

`Python · DeepSeek API · LangGraph · ChromaDB · FastAPI · Gradio`

> **设计原因**：现有框架（LangChain）高度封装、难以调试工具调用时序问题，因此从零实现 Agent 核心循环，获得对每一步推理-行动-观察的完全控制权。

- 基于 **LangGraph** 构建节点化 Agent 工作流，实现 **感知→推理→行动→观察** 完整 ReAct 闭环，条件路由支持自主纠错与重规划
- 设计统一工具接口规范，集成网络搜索、数学计算、天气查询、文件笔记等 **10+ 工具**，支持热插拔与动态注册
- 构建**双层记忆系统**（短期滑动窗口 + 长期JSON持久化），保障长对话上下文连贯性
- 基于 **ChromaDB** 实现本地文档（PDF/TXT）向量索引与检索，优化 Chunk Size 与 Top-K 参数降低幻觉率
- 开发 **FastAPI 后端 + Gradio WebUI**，端到端联调与 Docker 一键部署
- 设计 API 异常自动重试与降级回复机制，提升系统鲁棒性

### 航空专用轻量化大模型压缩与边缘部署 | 核心成员 | 2025.07 - 2025.09

`PyTorch · BERT · TensorRT · Jetson AGX Orin · 知识蒸馏`

> **设计原因**：航空场景机载算力有限（<50W功耗），无法运行110M参数的完整BERT，必须通过蒸馏+量化实现精度与延迟的平衡。

- 设计 **3层 Transformer 学生网络**，通过知识蒸馏（KL散度+交叉熵联合损失）对 BERT-base（110M）压缩，参数量**减少 83.6%**（110M → 18M）
- 利用 **TensorRT FP16 量化**与算子融合，在 Jetson AGX Orin 部署，推理延迟 **2100ms → 92ms（加速95.6%）**，GPU利用率 37% → 89%
- 为 Agent 在资源受限边缘端的低延迟推理提供关键技术验证

### 基于深度强化学习的无人机避障算法研究 | 第一作者 | 2025.09 - 2026.04

`Python · PyTorch · SAC · PPO · Gym-PyBullet-Drones`

> **设计原因**：真实无人机试飞成本高、风险大，选择 PyBullet 物理引擎仿真作为算法验证平台，安全投影层设计灵感来自机器人控制理论中的约束优化。

- 将无人机视为物理世界智能体，构建感知→推理→决策→执行→反馈完整决策闭环
- 设计**规则化安全投影层**（数学约束限制动作空间），训练初期碰撞率**降低 80%**
- 系统对比 PPO 与 SAC，开展12次独立训练，SAC在密集动态障碍下成功率比PPO高 **8%**
